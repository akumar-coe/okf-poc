# Telecom Network Overview
A modern mobile broadband network consists of several interconnected
network elements that work together to provide connectivity to users.
The 5G gNB is a radio access network node that provides wireless
connectivity between user equipment and the 5G core network. It is
responsible for radio communication with mobile devices.
The 5G UPF, or User Plane Function, is a core network component that
handles user-plane traffic. It forwards packets between the mobile
network and external data networks.
An IP router forwards IP packets between different network segments.
Routers can connect network elements and transport traffic between
different parts of the network.
The gNB and UPF communicate as part of the mobile network architecture.
The UPF also connects the mobile user plane to external data networks.
Together, the gNB, UPF and IP routing infrastructure support mobile
broadband services.
