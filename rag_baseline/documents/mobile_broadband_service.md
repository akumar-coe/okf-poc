# Mobile Broadband Service
The mobile broadband service provides data connectivity to mobile users
over a 5G network.
The service depends on multiple network elements. The 5G gNB provides
radio access to user equipment. The 5G UPF handles user-plane traffic
and forwards packets through the core network. IP routers provide packet
forwarding between network segments.
A disruption or performance degradation in any of these network elements
can affect the mobile broadband service.
High network latency is one example of a condition that can negatively
affect the quality of the mobile broadband service.
Troubleshooting the service may therefore require examining the gNB,
UPF and IP routing infrastructure.
