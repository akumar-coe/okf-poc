# High Network Latency
High network latency occurs when packets take longer than expected to
travel through the network.
In a mobile broadband environment, high latency can affect the user
experience and may result in slow application response or degraded
service quality.
Potentially relevant network elements include the 5G gNB, the 5G UPF
and IP routers.
Latency problems can originate from congestion, overloaded network
elements, inefficient routing or problems in the transport path.
When investigating high latency, network engineers may examine the
performance and connectivity of the gNB, UPF and IP routing
infrastructure.
High latency is therefore a network condition that can affect mobile
broadband service quality.
